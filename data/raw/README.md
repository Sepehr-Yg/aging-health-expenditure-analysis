# Raw Data Sources

This folder contains the raw datasets used in this analysis, downloaded directly from the World Bank Open Data platform.

## Datasets

### 1. Population ages 65 and above (% of total population)
- **Indicator code:** SP.POP.65UP.TO.ZS
- **Source:** World Bank Open Data
- **URL:** https://data.worldbank.org/indicator/SP.POP.65UP.TO.ZS
- **Download date:** 2026-07-06

### 2. Current health expenditure per capita (current US$)
- **Indicator code:** SH.XPD.CHEX.PC.CD
- **Source:** World Bank Open Data
- **URL:** https://data.worldbank.org/indicator/SH.XPD.CHEX.PC.CD
- **Download date:** 2026-07-06
